# degoog-plugins

A repository for degoog plugins I use personally.

## degoog-linkding

A slot plugin that injects a panel into degoog search results.
This panel contains a list of bookmarks extracted from linkding, currently positioned above the search results. The purpose of this is to somewhat try to mimic the [linkding-injector](https://github.com/Fivefold/linkding-injector) browser extension, since it does not currently support degoog.

I'm planning on trying to move this slot into the side, akin to the browser extension, it would be useful especially when more than 5 bookmarks are shown since it pushes the actual search down quite a bit.

Code created by AI and personally reviewed/altered, so... Take this with a bucket or salt.
